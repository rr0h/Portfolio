# Rohit Raj — Portfolio

A high-end, animated single-page portfolio built with vanilla HTML, CSS and JavaScript.

## Run locally

1. Keep all files in the same folder.
2. Open `index.html` in a browser.

For the best local development experience, use VS Code + Live Server.

## Included
- `index.html` — portfolio structure/content
- `style.css` — responsive styling, gradients, glassmorphism, animations
- `script.js` — particles, scroll reveals, cursor glow, 3D tilt, magnetic interactions
- `Rohit_Raj_Resume.pdf` — resume linked from the hero

## Personal links
The resume you provided did not contain the actual LinkedIn/GitHub URLs, so those have intentionally not been invented. Add them to the HTML if you want social/project buttons.

## Deploy
This is a static site, so it can be deployed directly to GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.
